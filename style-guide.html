Design System Reference

Style Guide

Every color, font, texture, animation, and component used across the Nico Alvarez portfolio — live, not screenshotted. Copy the values, reuse the classes, keep the system consistent.

01 — Palette

Five colors, one rule

Colored chips (moss, butter, red) always pair with black text. Black sections use paper/moss text. Paper sections use black/red text — moss is never used as small text on paper, since it fails contrast there.

Ink Black
#000000
Base background, primary text, borders, shadows
Moss
#8DB355
Labels on black, sticker chips, accent shapes
Butter
#FFEA93
Highlight marker on black sections, tape, CTA hover
Signal
#D90000
CTA button, stamps, the "red thread" accent
Paper
#F4EFE1
Neutral light section background, card faces
Paper Dim
#e9e1cb
Secondary text on black sections
:root{ --ink:#000000; --moss:#8DB355; --butter:#FFEA93; --signal:#D90000; --paper:#F4EFE1; --paper-dim:#e9e1cb; }
02 — Typography

Three fonts, three jobs

Display — headlines
Anton

Google Font · weight 400 only · always uppercase · used for h1/h2/h3

Labels — eyebrows, stickers, captions
Space Mono Bold

Google Font · weights 400 & 700 · used for nav, eyebrows, stickers, stamp text, footer

Body — paragraphs
Work Sans — the quick brown fox jumps over the lazy dog.

Google Font · weights 400–800 · default body font for all running text

font-family:'Anton', sans-serif; /* headlines */ font-family:'Space Mono', monospace; /* labels/captions */ font-family:'Work Sans', sans-serif; /* body */

05 — Components

The signature: paper-cutout system

Every card, tag, and frame shares one language: black outline + hard offset shadow + slight rotation — like something taped down by hand. That repetition is what ties five different sections into one page.
